# PC-0021 — free cloud decision evidence

Updated decision, Azure comparison and migration backlog (8 November 2026):
[CLOUD_MIGRATION.md](CLOUD_MIGRATION.md). The report below records the original review.

Checked **2026-11-07**, official public sources only; no account access or deployment.

**Recommendation: retain local Docker for a strict zero-additional-monthly-cost requirement.** Oracle is the closest cloud fit if interruptions and administration are acceptable; none establishes guaranteed, continuously available $0 hosting for this stack.

| Option | Verified allowance and practical fit | Cost and continuity limits |
|---|---|---|
| **Oracle Always Free VM** | Current A1 allocation: **1,500 OCPU-hours + 9,000 GB-hours/month**, equivalent to **2 OCPU/12 GB**, not the older 4/24 allowance. **200 GB** combined boot/block storage; **five volume backups**. Self-host Postgres durably and run Docker plus both scheduled workers on one VM; ARM images must be compatible. [Allowances](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm) | Ongoing Always Free is separate from $300/30-day trial. Card verification required; Oracle says no charges unless explicitly upgrading. Remain unupgraded. [Signup](https://docs.oracle.com/en-us/iaas/Content/GSG/Tasks/signingup_topic-Sign_Up_for_Free_Oracle_Cloud_Promotion.htm). Home-region capacity can be unavailable; VM reclaimable when seven-day CPU/network utilization and A1 memory meet idle thresholds. This small workload may qualify—an inference. [Policy](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm). EU home regions include Frankfurt/Amsterdam, subject to signup availability. [Regions](https://www.oracle.com/cloud/public-cloud-regions/) |
| **Cloud Run + Neon Free Postgres** | Request-based monthly allowance: **180,000 vCPU-seconds, 360,000 GiB-seconds, two million requests**, aggregated per billing account. EU regions available; service filesystem is ephemeral. [Pricing](https://cloud.google.com/run/pricing), [container contract](https://docs.cloud.google.com/run/docs/container-contract). Convert hourly/daily loops into finite authenticated executions: **three Scheduler jobs free/account**. [Scheduler](https://cloud.google.com/scheduler/pricing). Neon: **1 GB/project**, **100 CU-hours/project/month**, **5 GB egress/project/month**; Frankfurt available. No card; ongoing free. [Pricing](https://neon.com/pricing), [regions](https://neon.com/docs/introduction/regions) | Neon sleeps after five inactive minutes; exhausted compute/egress suspends access, storage limits block growth without overage billing or data deletion. Six-hour restore history/one snapshot; independent exports needed. [Limits](https://neon.com/faqs/free-plan-limits-and-quotas). Google requires ongoing billing/payment setup after its 90-day trial; excess usage is billable. EU internet egress, image storage/builds and other services need separate accounting. [Free program](https://docs.cloud.google.com/free/docs/free-cloud-features). Cloud Run spend caps now exist, but enforcement is delayed and overages remain billable; they cover one service/project and exclude credits. **No exact $0 guarantee.** [Caps](https://docs.cloud.google.com/billing/docs/how-to/budgets-spend-caps) |
| **Render Free** | **750 web-instance hours/workspace/month**, Frankfurt available. No payment method means bandwidth exhaustion suspends services. [Free policy](https://render.com/docs/free), [regions](https://render.com/docs/regions) | Reject as complete solution: web sleeps after 15 minutes; no persistent disk; free Postgres **1 GB expires after 30 days**, then deletion after grace period. Workers lack free plans; cron costs **minimum $1/job/month**. External Neon alone does not solve reliable free scheduling. [Free policy](https://render.com/docs/free), [cron](https://render.com/docs/cronjobs) |

Before public hosting: owner authentication and authorization/isolation on every endpoint, HTTPS, protected secrets, restricted Postgres access, tested encrypted backups/restores, and a deliberate authenticated remote interface if needed for stdio MCP. These are prerequisites, not medical/legal compliance guarantees. Free allowances exclude external paid APIs and can change.
